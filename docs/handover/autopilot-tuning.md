## 1. 问题现象（整定前，用户报告）

| 模式 | 现象 |
|---|---|
| 速度保持（AAP airspeed hold，油门） | 固定步长 0.2s 时油门在 0/100% 之间反复横跳（PWM）；改可变步长后变成**高频抽搐**（非 PWM） |
| 航向保持（AAP heading hold） | **振荡并发散** |
| AAP 高度保持（升降舵） | 同类参数问题（用户观察到） |
| HOLD ALT（悬停高度保持） | 同类参数问题（用户观察到抖动） |
| 坡度保持（bank hold） | 与航向级联；随 heading 一起整定 |

根因判断：官方 DG 的 AAP 是 **2006 年的简化控制律**（比例 + 未滤波的数值微分，增益硬编码、无死区、无变化率限制、无按步长归一化），不是工程 PID。固定步长 0.2s 时每帧增量大 → 饱和成 PWM；可变步长（dt≈0.02~0.04s）时微分噪声被放大 → 高频抽搐；heading 外环增益相对 bank 内环过大 → 级联振荡发散。

## 2. 控制律与修改（源码位置）

### 2.1 Lua 脚本：`Src/Vessel/DeltaGlider/Script/aap.lua`

> 运行时副本：`install64\Orbiter\Script\DG\aap.lua`（**改这个文件后重启游戏即生效，无需编译**）
> 原版备份：`D:\AI_projet\orbiter\temp\aap.lua.orig`

**控制周期**：每个物理帧执行一次（`proc.skip()` 协程恢复）；`dt = oapi.get_simstep()`（当前物理步长，可变步长下逐帧变化）。所有"变化率"都按 `×dt` 实现（连续时间语义），不要写成固定每帧增量。

#### (1) `spd_ap` 速度保持 → 主油门

原律（`alpha = beta = 1`）：

```
acc    = (spd - spd0)/dt          -- 未滤波数值微分
dspd   = target - spd
dthrott= (dspd*alpha - acc*beta)*dt
throttle += dthrott               -- 油门是积分量
```

| 项 | 原值 | 新值（代码内变量） |
|---|---|---|
| 速度误差积分增益 alpha | 1.0 /s | **0.15 /s** |
| 加速度反馈（D）增益 beta | 1.0 | **0.2** |
| 加速度微分滤波 | 无 | 一阶低通：`acc_f = 0.8*acc_f + 0.2*acc` |
| 速度误差死区 | 无 | **1.0 m/s** |
| 油门变化率限制 | 无 | **1.0 /s**（每帧 ≤ `rate_max*dt`） |
| 油门限幅 | 无显式 | 显式 0…1 |

#### (2) `alt_ap` AAP 高度保持 → 升降舵

原律：`delev = (dslope*0.1 + dslope_rate)*(dt*10.0)`，等效连续形式：

```
d(elev)/dt = 1.0*dslope + 10.0*dslope_rate     -- P=1.0/s, D=10
```

新参数：

| 项 | 原值 | 新值 |
|---|---|---|
| 外层：高度误差→目标爬升角 | `RAD*1e-2*dalt`，限幅 +30°/−20° | **不变** |
| 内层 P（爬升角误差→升降舵变化率） | 1.0 /s | **0.3 /s**（代码 `kp_slope`） |
| 内层 D（爬升角误差变化率） | 10.0 | **2.0**（`kd_slope`） |
| 微分滤波 | 无 | 低通 0.8/0.2（`dslope_rate_f`） |
| 高度误差死区 | 无 | **2.0 m**（`db_alt`） |
| 升降舵变化率限制 | 无 | **1.0 /s**（`rate_max`） |
| 升降舵限幅 | ±1 | 不变 |

#### (3) `bank_ap` 坡度保持 → 副翼（heading 级联的内环）

原律：`dail = (-dbnk*0.1 + rate*0.3)*(dt*5.0)`，等效：

```
d(ail)/dt = -0.5*bank_error + 1.5*roll_rate
```

| 项 | 原值 | 新值 |
|---|---|---|
| P（坡度误差） | 0.5 /s | **1.2 /s**（`kp_bank`，提高内环带宽） |
| D（滚转率阻尼） | 1.5 | **2.0**（`kd_bank`） |
| 滚转率滤波 | 无 | 低通 0.8/0.2（`rate_f`） |
| 坡度死区 | 无 | **0.3°**（`db_bank`） |
| 副翼变化率限制 | 无 | **1.0 /s**（`rate_max`） |
| 副翼限幅 | ±1 | 不变 |

#### (4) `heading_ap` 航向保持 → 目标坡度（外环）

原律：`dbank = (-dhdg*100 + rate*1000)*dt`，等效：

```
d(tgtbank)/dt = -100*yaw_error + 1000*yaw_rate    -- 注意：tgtbank 是增量式（基于当前坡度）
```

| 项 | 原值 | 新值 |
|---|---|---|
| P（航向误差） | **100 /s** | **3.0 /s**（`kp_hdg`） |
| D（偏航率阻尼） | **1000** | **10.0**（`kd_hdg`） |
| 偏航率滤波 | 无 | 低通 0.8/0.2（`rate_f`） |
| 航向死区 | 无 | **0.5°**（`db_hdg`） |
| 目标坡度变化率限制 | 无 | **0.5 rad/s**（`rate_max`） |
| 目标坡度限幅 | ±0.3π（±54°） | 不变 |

**发散原因**：原 heading P=100/s（1° 误差 → 1.75 rad/s 目标坡度变化）远超 bank 内环的跟踪能力（0.5/s），级联带宽严重失配 → 振荡发散；两个环的 D 项均为未滤波数值微分，噪声直接进舵面。

### 2.2 C++：`Vessel::HoverHoldAltitude()`（DG 的 HOLD ALT 悬停高度保持）

> 位置：`Src/Orbiter/Vessel.cpp`（约 4116 行）；状态结构 `Src/Orbiter/Vessel.h` 的 `struct HoverHoldAlt`（新增 `valt_f` 滤波状态）；`SetHoverHoldAltitude()` 中初始化 `valt_f=0`。
> **注意：这是核心 Orbiter 代码，改后必须重新编译 `Orbiter.exe`。**
> 更新间隔：`holdaltDT = 0.1`（模拟时间，由 `UpdateBodyForces` 检查 `td.SimT1 > hoverhold.T` 触发）。

原律：

```
vh_tgt = -dh*0.1                 (限幅 ±20 m/s)
dvh    = vh_tgt - vh
a_tgt  = dvh                     // accel = 速度误差 (有效增益 1.0 /s)
da     = a_tgt - ah              // ah = (vh-valt)/dt 未滤波数值微分
dlvl   = da / a_max              // a_max = 最大悬停推力/质量
dlvl_max = dt                    // 每步最多变化 dt (≈1.0 /s)
IncThrusterGroupLevel(THGROUP_HOVER, dlvl)   // 积分器
```

| 项 | 原值 | 新值 |
|---|---|---|
| 外层：高度误差→目标垂直速度 | 0.1 /s（±20 m/s） | **不变** |
| 垂直速度误差→目标加速度 | 1.0 /s | **0.3 /s** |
| 垂直加速度反馈（D） | 原始数值微分 | **低通滤波 0.8/0.2**（`hoverhold.valt_f`） |
| 位置死区 | 无 | `|dh| < 0.5 m && |vh| < 0.3 m/s` → `vh_tgt = 0` |
| 悬停油门变化率 | `dlvl_max = dt`（≈1/s） | **`dlvl_max = dt*0.5`（0.5/s）** |

## 3. 设计原则（给继续整定的参考）

1. **所有增益按"连续时间"语义写**：输出变化率 × dt，不写固定每帧增量，否则固定步长（0.2s）与可变步长（0.02~0.04s）行为完全不同。
2. **微分项必须低通滤波**：数值微分 `(x-x0)/dt` 在 dt 小时放大测量噪声；一阶滤波系数目前固定 0.8/0.2（若 dt 变化很大，可考虑改为 `alpha = dt/(tau+dt)`）。
3. **死区**用于抑制小误差持续抖动，代价是静差（当前速度 1 m/s、高度 2 m、坡度 0.3°、航向 0.5°、HOLD ALT 高度 0.5 m）。
4. **变化率限制**替代单一的"增益调小"：既降抖动又保留大误差时的响应能力。
5. **级联控制带宽**：内环（bank）应明显快于外环（heading）；若 heading 仍发散，优先提高 bank 环 P（或降低 heading P），不要只降 heading 的 D。
6. **控制周期 = 物理帧**（AAP 每帧恢复协程）；时间加速（warp>1）会改变 SimDT，从而改变控制周期——**整定和测试都应在 1x 时间加速下进行**。

## 5. 验证与微调指南

### 测试方法（建议 1x 时间加速、大气内）
1. **速度保持**：目标速度给 +50 m/s 阶跃，观察油门是否连续变化、无 0/1 横跳、无高频抖；
2. **航向保持**：从 0° 给 90° 目标，观察是否平稳转弯收敛（不振荡、不发散）；
3. **坡度保持**：单独给 ±30° 坡度，观察滚转平滑性；
4. **HOLD ALT**：悬停/低空保持，观察悬停油门与高度是否静定；
5. 记录：是否收敛、超调、残余振荡频率/幅度、风/动压条件。

### 若仍有问题（微调方向）

| 现象 | 调整 |
|---|---|
| 速度保持仍高频抖 | `alpha` 0.15→0.08；死区 1.0→2.0；`beta` 0.2→0.1 |
| 速度收敛太慢 | `alpha` 0.15→0.25~0.3；`rate_max` 1.0→1.5 |
| 航向仍振荡 | `kp_hdg` 3→2；`kd_hdg` 10→15；或提高 `kp_bank` 1.2→1.6 |
| 航向转向太慢 | `kp_hdg` 3→4~5；`rate_max` 0.5→0.8 |
| 坡度抖动/超调 | `kp_bank` 1.2→0.8；`kd_bank` 2.0→2.5；死区 0.3°→0.5° |
| HOLD ALT 抖动 | `a_tgt` 增益 0.3→0.2；`dlvl_max` 0.5→0.3；死区 0.5→0.8 m |
| HOLD ALT 下沉/上浮慢 | 增益 0.3→0.4；`dlvl_max` 0.5→0.8 |

### 已知风险 / 需要整定鱼重点确认
1. **用户实测反馈尚未回归**（当前只有整定前的现象描述）；
2. `bank_ap`/`heading_ap` 的 D 项**符号沿用官方代码**（未验证符号约定：如果 roll rate 反馈实际应为负，当前可能表现为"阻尼变反"——若测试发现振荡更严重，先把 `kd_bank`/`kd_hdg` 的符号取反试）；
3. 级联带宽：heading 外环 P=3/s、bank 内环 P=1.2/s，内环实际响应还取决于滚转力矩/气动阻尼，可能仍需提高 bank P；
4. 固定步长 `FixedStep=0.2` 时 dt 很大：死区/变化率限制按 dt 缩放，但控制周期仍是 0.2 模拟秒——**大步长下不建议用 AAP 正常飞行**（时间流速 6.6x），正常游玩用可变步长；
5. `HoverHoldAltitude` 的滤波系数 0.2 是按 0.1s 更新间隔估的，如果更新间隔随步长变化（固定步长 0.2 时实际每帧 0.2s 更新），滤波时间常数会变——可考虑用 `tau/(tau+dt)` 形式。
