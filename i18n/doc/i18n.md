# Orbiter 汉化（i18n）体系说明

翻译数据全部**外置为 UTF-8 `.po` 文件**（.po 子集：`msgid`/`msgstr`/`msgctxt`），由核心与插件在运行时通过 `oapiRegisterTranslationCatalog` 加载；代码中不再编译进大段中文翻译表。改翻译只需编辑安装目录下的 `.po` 文件，无需重新编译。

## 目录结构

```
i18n/
├── locales/zh_CN/           运行时加载的翻译文件（安装到 <Orbiter>/i18n/locales/zh_CN/）
│   ├── core.po              核心 UI（主程序/MFD/对话框/残骸消息）
│   ├── launchpad.po         启动器（Launchpad）窗口文本
│   ├── scenario.po          场景/文件夹说明（msgctxt = "scenario.description"）
│   │                        以及星座名（msgctxt = "constellation"）
│   ├── plugins.po           插件/飞船模块界面文本
│   └── d3d9client.po        D3D9Client 设置对话框文本（由插件自行加载）
├── core/                    核心本地化实现与保留的布局/算法数据
│   ├── Localization.h/.cpp  翻译表、Tr/TrContext、语言设置、编码转换、
│   │                        .po 解析器（RegisterTranslationCatalog）、oapiTr 导出实现
│   ├── MfdZh.inc            MFD 中文布局偏置参数 + 内置 MFD 别名表（非翻译表）
│   ├── InstrumentZh.inc     玻璃座舱面板/HUD 的中文标签与字号参数（非翻译表）
│   ├── ZhCommon.inc         汉化排版算法（字体/测宽/右对齐/列布局等，非翻译表）
│   └── LaunchpadZh.inc      仅保留 Extra 页“轨道稳定化”对话框的直接控件文本逻辑
├── d3d9client/              （原 D3D9ClientZh.inc 已外置为 d3d9client.po）
├── scneditor/EditorZh.inc   场景编辑器对话框本地化逻辑（文本在 plugins.po）
├── vessels/                 飞船模块本地化逻辑（文本在 plugins.po）
├── plugins/                 MFD 按钮中文标签数组（按钮图集无英文文本键，保留数组）
└── doc/i18n.md              本文档
```

## 运行时加载

1. **核心**：`InitLocalization()` 构建空表后调用 `LoadBundledCatalogs()`，依次加载
   `i18n/locales/zh_CN/core.po`、`launchpad.po`、`scenario.po`、`plugins.po`（相对游戏工作目录）。
   文件缺失时静默跳过（该部分显示英文，不影响启动）。
2. **插件**：在 `InitModule()` 中调用 `oapiRegisterTranslationCatalog(path)` 加载自己的 `.po`
   （例如 D3D9Client 加载 `i18n/locales/zh_CN/d3d9client.po`）；插件也可以改用
   `oapiRegisterTranslation` 逐条注册，或发布自己的翻译文件。
3. **安装**：CMake `install(DIRECTORY i18n/locales DESTINATION <install-root>/i18n)`，
   发行版自带 `.po` 文件；用户可直接编辑安装目录中的 `.po` 来修正/扩展翻译。

## .po 文件格式（子集）

```po
# 注释行
msgid "OpenOrbiter Launchpad"
msgstr "OpenOrbiter 启动器"

# 上下文翻译（同词不同义）：msgctxt 区分
msgctxt "scenario.description"
msgid "<h1>Orbiter Challenges</h1> ..."
msgstr "<h1>轨道挑战</h1> ..."
```

- UTF-8 编码（无 BOM 亦可）；`\n`、`\t`、`\r`、`\"`、`\\` 转义与 C 字符串一致。
- 同一 msgid 重复出现时后加载者覆盖先加载者（与旧编译期表行为一致）。
- `msgctxt` 条目进入上下文表，只能通过 `oapiTrContext`/`orbiter::TrContext` 查询；
  普通 `msgid` 条目进入主表，`oapiTr` 查询。

## 对外 API（SDK，见 `Orbitersdk/include/OrbiterAPI.h`）

| 函数 | 说明 |
|---|---|
| `oapiTr(english)` | 翻译 UI 字符串（英文模式返回原文） |
| `oapiTrContext(context, english)` | 上下文翻译 |
| `oapiTrName(english)` / `oapiGetOriginalName(localized)` | 名称翻译与反查 |
| `oapiGetLocale()` | `"zh_CN"` / `"en"` |
| `oapiRegisterTranslation(locale, en, zh)` | 运行时逐条注册（只增不覆盖） |
| `oapiRegisterTranslationCatalog(path)` | 加载 .po 子集（支持 msgctxt） |
| `oapiUtf8ToWide` / `oapiWideToUtf8` / `inline oapiUtf8ToWString` | UTF-8/UTF-16 转换 |
| `oapiZhActive()` | 当前是否中文模式 |

## 编写规则

- **英文为键**：`msgid` 必须是代码里的英文原文（大小写、标点、空格完全一致）；英文模式不查表、零影响。
- **占位符顺序**：带 `%s` 等格式的模板，`msgstr` 中占位符数量与顺序必须与 `msgid` 一致。
- **语言判断**：用 `oapiZhActive()`（插件）或 `orbiter::IsChinese()`（核心），不要用翻译文本比较。
- **UTF-8**：`.po` 文件与源码中文字符串均为 UTF-8；Win32 宽字符 API 用 `oapiUtf8ToWString`/`oapiWideToUtf8`。
- **HTML 中文页**：场景描述中的 URLDESC 类型使用 `*_zh.htm` 中文页面（如 `CurrentState_img_zh.htm`），
  保存 UTF-8 时必须带 `<meta http-equiv="Content-Type" content="text/html; charset=utf-8">`，
  否则 IE 控件按系统 ANSI 解码会乱码。
- **Lua 脚本**：内置脚本（场景 `Script` 字段加载的 Lua，如 Challenges、Demos 教程）通过 Lua 全局函数
  `tr("english")` 查询翻译表，文本放在 `scripts.po`。注意 Lua 中 `\` 行尾续行会**保留换行符**，
  多行文本的 msgid 必须包含这些换行（例如 `Flight challenge:\n\n...`）。

## 仍需留在代码中的数据（无法数据化）

- `i18n/core/MfdZh.inc`、`InstrumentZh.inc`：MFD/面板/HUD 的中文**布局偏置参数**与按钮标签数组
  （按钮图集渲染没有英文文本键，只能按按钮索引替换；偏置数值与代码坐标强耦合）。
- `i18n/core/ZhCommon.inc`：汉化排版**算法**（字体缓存、测宽、右对齐多列布局、面板/HUD 流程）。
- `LaunchpadZh.inc` 段 B：Extra 页“轨道稳定化”对话框的直接控件文本（依附于 Win32 控件 ID）。
- `i18n/plugins/`、`i18n/luainterpreter/` 下的按钮中文标签数组（同上，按索引替换）。
- `Html/Scenarios/CurrentState*_zh.htm`：场景描述 HTML 中文页。

## 迁移记录（2026-11）

- 原编译期翻译表（`Localization.cpp` 内 `g_translations` 数组 + `DialogZh/LaunchpadZh/ScenarioDescZh/
  ScenarioScnZh/WreckMsgZh/PluginZh/D3D9ClientZh` 数据）已全部导出为 `i18n/locales/zh_CN/*.po`
  并在运行时加载；对应 `.inc` 数据文件已删除。
- 插件私有 `wchar_t` 映射表已迁移为 `oapiTr` + `.po` 数据；模块只保留本地化逻辑。
- 重复 UTF-8 转换 helper 统一为 SDK 的 `oapiUtf8ToWString`。
- 翻译冲突（同词多义）用 `msgctxt` 上下文翻译区分；重复译名已统一。
- 残骸/撞击消息改为 `.po` 模板（`core.po`）。

## 未汉化 / 保留英文的部分

- HUD 纹理字符集中的文本（座舱 HUD 使用贴图字符，需要时用 `oapiZhHudText` 叠加）。
- 部分第三方插件（XRSound、TerrainToolKit 等）未做界面汉化。
- URLDESC 模式下除 `CurrentState` 外的少数 CHM 内置帮助页未提供中文副本。
